# Architecture Decision Records

Each ADR records a decision **currently in effect**, in present tense: what we
do, why, and the constraint that makes the obvious alternative wrong.

Keep them true rather than append-only. When a decision drifts from what the
code does, correct the ADR in place; when it stops holding, delete it (git
history is the archive). A decision that replaces another rewrites or removes
the one it replaces instead of stacking a "superseded by" note on top.
